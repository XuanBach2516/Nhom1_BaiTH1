1. Tóm tắt nội dung thực hành

Bài thực hành tập trung vào việc khai thác các công cụ Trí tuệ nhân tạo (AI) để hỗ trợ thao tác kỹ thuật, xử lý sự cố hệ thống và ứng dụng công nghệ có trách nhiệm:

Phần 1: Cấu hình phần cứng & phần mềm (CLO13)

Tra cứu và đọc thông số phần cứng thực tế qua Task Manager: CPU Intel Core i3-10105 (4 nhân 8 luồng, 3.70 GHz), RAM 8 GB, Ổ cứng SSD (Disk 0 chia phân vùng C: và D:).

Cài đặt Notepad++ (x64) trên Windows 10, cấu hình chuẩn thụt lề 4 khoảng trắng (PEP 8) và thiết lập phím tắt Ctrl + F5 chạy script Python qua lệnh cmd /k python "$(FULL_CURRENT_PATH)".

Phần 2: Giải quyết sự cố kỹ thuật đơn giản (CLO11)

Xử lý lỗi mất kết nối Wi-Fi bằng việc làm mới IP và xóa cache DNS qua Command Prompt (ipconfig /release, /renew, /flushdns).

Phân tích nguyên nhân Notepad++ bị treo khi mở tệp Python lớn (>1MB) do cơ chế tô màu cú pháp (Syntax Highlighting) và đưa ra phương án xử lý chuyển sang chế độ Normal Text hoặc dùng VS Code.
